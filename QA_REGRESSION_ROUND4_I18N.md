**I18N-R4-01 — PhoneInput: typing a number with its prefix now silently stores a wrong prefix and a truncated number (regression of the R3-L9 "+39 +39" fix).** REGRESSION of `9481d5d` (PR for HQ-R3-12).
- Where: every form that uses `components/ui/PhoneInput.tsx` — `/register` (anonymous), `/teacher/profile`, `/student/profile`, `/school/profile`, HQ/school team invites, school teacher invite, HQ schools/new. Code: `PhoneInput.tsx:201-215` (`emit()` — a number starting with "+" is re-split immediately on every keystroke) + `splitPhone()` fallback `^(\+\d{1,4})\s*(.*)$` (`:171-183`), which accepts a 1-digit "prefix".
