### Observations (not filed as findings)

- **Toggle off ≠ API off.** With `student_tutorials_enabled=false`, `GET /api/tutorials/` still returns 200 with 6 rows and `GET /api/tutorials/<pdf>/file/` still 200; only the sidebar entry and the page (client-side redirect) are hidden. Consistent with the HQ hint text ("menu e pagina") and the content is public anyway — flagging in case the intent was to hide the content too (`dumps/tut-api.txt`, `## 5. Toggle`).
- **Logged-in student, `language_preference="en"`, on `/it/student/tutorials`:** the language filter preselects **Inglese** (`Lingua · 1`, group "Bookings" shown, Italian tutorials hidden). This is what the code does on purpose (`preferred = user?.language_preference || uiLocale`, comment "Lingua di partenza: quella del profilo"), so not a bug — but a student browsing the site in Italian with an English profile sees English guides first. Product call. Anonymous: `/it` → Italiano, `/en` → English ✔ (`dumps/tut-student.txt`).
- **Mobile:** `document.scrollWidth = innerWidth = 390` (no horizontal scroll). The only elements past the right edge are the layout's "Apri Barra Laterale" handle (`right=403`) — a fixed handle of `StudentLayout`, not tutorials-specific (`dumps/tut-student.txt`, `shots/tut-student-mobile.png`).
- **Local nginx is stale** (see Not run): the running container has an `/etc/nginx/nginx.conf` inode from Sep 6 (2973 bytes) and `nginx -T` contains **no** `nosniff` at all, while the repo file (Sep 10, e532a6b) has it on `/internal-media/` and `/media/public/`. Recreate the nginx container before trusting header checks locally.
