Executive Summary

🔴 CRITICAL ISSUES (Must Fix Before Deploy)

1. Unrestricted School Admin PATCH — Mass Assignment

CRITICAL Security

File: src/app/api/hq/schools/[id]/route.ts (line 22)

Issue: PATCH endpoint accepts arbitrary fields without validation. Attacker can inject: platform_fee_percentage, stripe_account_id, active status, user_id.

Impact: HQ team members can modify school configs, bypass platform fees, or hijack Stripe accounts.

Fix: Implement field whitelist + cross-check HQ sub-role permissions

Estimated Time: 20 minutes

2. Attendance Logic Inverted — Revenue Loss

CRITICAL Financial

File: src/app/api/attendance/[lessonId]/route.ts (line 142)

Issue: Status mapping is backwards:

// WRONG ❌ status: statusMap[r.status_id]?.burns_credit ? 'present' : 'no_show'

When burns_credit=true (no-show), status set to 'present'. Credits are NOT burned when they should be.

Impact: Students who don't attend still get credits refunded. Schools lose revenue. Cancellation policy completely broken.

Fix: Invert logic to: burns_credit ? 'no_show' : 'present'

Estimated Time: 15 minutes

3. Stripe Webhook Account Isolation Missing

CRITICAL Multi-Tenant

File: src/app/api/webhooks/stripe/route.ts

Issue: No account verification. Webhook from school A with school B's metadata → credits added to wrong student across entire network.

Impact: One school can manipulate balances at another school. Attacker can issue refunds, activate subscriptions cross-tenant. This is a multi-tenant isolation breach.

Fix: Validate event.account matches school's stripe_account_id before processing

Estimated Time: 20 minutes

4. Missing Rate Limiting on Auth Endpoints

CRITICAL Security

Files: /api/auth/register, /api/auth/send-reset

Issue: No rate limiting. Attackers can:

  • Enumerate valid emails via timing attacks
  • Brute-force weak passwords
  • Mass-register accounts (DoS)

Impact: Account enumeration, credential stuffing attacks, mass registration abuse.

Fix: IP-based rate limiter (5-10 req/min) using @upstash/ratelimit

Estimated Time: 45 minutes

5. Stripe Metadata Type Mismatch

CRITICAL Payment

File: src/app/api/stripe/checkout/route.ts (line 143) + webhook

Issue: Stores user.id (Supabase auth ID) in Stripe metadata, but DB expects students.id (students table ID). Two different ID types.

Impact: Student packages inserted with wrong student_id. Credits don't attach to correct student. Payment processing broken.

Fix: Store students.id not auth.users.id in metadata

Estimated Time: 30 minutes
